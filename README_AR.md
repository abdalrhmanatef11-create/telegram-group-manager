# بوت إدارة الانضمام إلى جروب تيليجرام

هذا مشروع جاهز كبداية لبوت تيليجرام لإدارة الانضمام بطريقة تعتمد على موافقة المستخدم.
لا يقوم بإضافة أشخاص تلقائيًا من قائمة يوزرات، ولا يتجاوز إعدادات الخصوصية أو قيود تيليجرام.

## الميزات
- `/start` رسالة ترحيب.
- `/joininfo` يرسل رابط الانضمام الذي يضبطه المشرف.
- `/status` يعرض معرّف المستخدم.
- `/admin` يعرض إعدادات التشغيل للمشرفين.
- إشعار المشرفين عند وصول طلب انضمام إلى الجروب (إذا كان الجروب مضبوطًا على طلبات الانضمام).

## التشغيل
1. أنشئ بوتًا من `@BotFather` وخذ التوكن.
2. ارفع الملفات إلى Replit أو استضافة Python تدعم عملية تشغيل مستمرة.
3. أضف المتغيرات التالية في Secrets / Environment Variables:
   - `BOT_TOKEN`: توكن البوت من BotFather.
   - `ADMIN_IDS`: معرّفات المشرفين مفصولة بفواصل، مثل `123456789,987654321`.
   - `GROUP_ID`: معرّف الجروب (اختياري لهذه النسخة).
   - `INVITE_LINK`: رابط دعوة الجروب الذي أنشأه المشرف.
4. ثبّت الحزم:
   `pip install -r requirements.txt`
5. شغّل:
   `python bot.py`

## ملاحظات مهمة
- لا ترسل توكن البوت لأي شخص ولا تضعه داخل ملف الكود.
- أضف البوت إلى الجروب وامنحه الصلاحيات اللازمة إذا أردت استقبال إشعارات طلبات الانضمام.
- لاستخدام إشعارات طلبات الانضمام، اجعل رابط الدعوة يتطلب موافقة المشرفين، وأضف البوت بصلاحيات مناسبة.
- هذه النسخة لا تنفذ دعوات جماعية ولا تتعامل مع كلمات مرور حسابات المستخدمين.
